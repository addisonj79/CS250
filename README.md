# CS250
I interpret user needs and implement them into the program by conducting interviews and surveys and converting them into tasks for developers to work on. Ensure each story has a clear definition to meet the user's expectations. Gather feedback and implement features incrementally. User stories help by providing clarity, alignment, and a more user focus on development. I approach developing programs by gathering the user's needs and creating user stories. I then plan and start development by building in small increments, continuously testing and refining. Ensure it meets the criteria, works as expected, and then releases the software. A few agile processes that I hope to incorporate into future development are the daily stand-ups, which I believe are very helpful in promoting collaboration and transparency. I also want to integrate user feedback loops to gather real-world feedback. Being a good team member means communicating effectively, collaborating proactively, and taking ownership of mistakes.
